# 急症识别与院前处理

以下内容的定位是「识别 + 争取送医时间」，不构成在家处置的授权。错误催吐、错误降温、错误包扎都可能直接致命；拿不准时的正确动作永远是打电话给宠物医院或立刻送医。

## 红旗信号清单：出现任一项，30 分钟内就医
| 表现 | 判读要点 |
| --- | --- |
| 呼吸困难、张口呼吸（猫）、黏膜发紫或苍白 | 猫张口/腹式呼吸几乎总是急症；减少刺激、供氧送医 |
| 抽搐、意识丧失、无法站立 | 单次>5 分钟或 24 小时内反复发作＝癫痫持续状态 |
| 公猫频繁蹲猫砂盆却无尿团、嚎叫、舔下腹 | 尿道阻塞，按小时计急症，勿在家观察 |
| 腹围迅速膨胀＋干呕吐不出东西＋流涎 | 疑胃扭转（GDV），大型深胸犬高发，立即手术医院 |
| 呕血、咖啡渣样呕吐物、血便、酱油色尿 | 消化道出血/溶血/横纹肌损伤，当日就诊 |
| 完全拒食拒水超过 24 小时 | 猫尤危（有脂肪肝风险）；幼宠与玩具犬易低血糖 |
| 持续呕吐>24 小时或每小时都吐、饮水即吐 | 脱水与电解质紊乱，须排查异物、胰腺炎、中毒 |
| 体温>40.5 ℃ 或 <37.5 ℃、疑似中暑或中毒 | 立即送医并同时记录接触史 |
| 晕厥、突发后肢瘫痪、拖行、颈背疼痛尖叫 | 神经/血管急症（椎间盘、动脉血栓），硬板搬运 |
| 外伤、车祸、高处坠落、咬伤穿透伤 | 外表轻伤也可能内脏破裂，一律就诊检查 |
| 注射疫苗或用药后 30 分钟内面部肿胀、荨麻疹、呼吸急促、虚脱 | 过敏性休克，就地回医院急救 |
| 孕畜强力宫缩 20～30 分钟无产出、羊水破后 1～2 小时未产、大量暗绿或脓性分泌物 | 难产，急诊 |

## 送医前的通用动作
1. 先电话医院说明情况，让对方准备抢救床位与氧气；
2. 记录时间与观察量：症状何时开始、持续多久、进食饮水排尿排便情况、估算摄入的毒物量与体重；
3. 带上相关物证：药盒/包装/植物枝叶/呕吐物照片/疫苗本/正在使用的药物清单；
4. 减少应激：暗光、安静、航空箱或硬板担架，不要一路追问式地抱、晃、拍；
5. 不要给任何食物、水或人用药物，除非兽医明确指示（可能需要麻醉手术）。

## 心跳呼吸骤停与心肺复苏（认知层面）
2024 年 RECOVER 指南对犬猫 CPR 的要点：按压频率 100～120 次/分，按压与通气比 30:2（单人施救），按压深度约为胸廓厚度的三分之一到二分之一；深胸犬在心脏最低点按压，桶状胸犬在胸廓最宽处按压；每连续按压 2 分钟再评估一次，中途不中断；通气方式为口对口鼻（包住鼻口吹气，见胸廓抬起即可）。

必须同时知道的是：院外与急诊条件下的存活率都很低（犬约 5%～7%，猫约 1%～19%），CPR 的意义在于为送医争取时间，而不是替代送医。正确做法是边做 CPR 边让人送往最近的有抢救条件的医院。

## 大出血与外伤
- 用干净纱布或毛巾**持续直接压迫 5～10 分钟不要反复掀开查看**（掀开会破坏正在形成的血凝块）。
- 止血带仅用于四肢喷射性大出血且压迫无效的情况，需记录上带时间并每 5～10 分钟放松一次，绑得过久会造成肢体坏死。
- 穿透伤插入物（树枝、刀片、钢筋）**留在原位固定后送医**，拔除会造成无法控制的大出血。
- 眼球脱出或破裂：干净湿纱布轻覆（勿加压）、遮光、立即送医，切勿自行按压眼球或用药。
- 化学物溅入眼内是唯一需要在家先处理的情形：用大量清水或生理盐水持续冲洗数分钟后再送医。

## 抽搐发作
移开周围硬物、垫护头部、保持环境安静昏暗、**不要往嘴里塞任何东西、不要按压抱住**（会造成咬伤与骨折，且抽搐时不会「咬到自己舌头」）。记录发作起止时间与表现（一侧肢体？全身？发作后多久恢复意识），发作超过 5 分钟、连续发作、或 24 小时内多次发作属急诊。发作后测量体温与检查牙龈颜色：抽搐常伴发高热与低血糖，需送医查明原因（中毒、颅内病变、代谢病、癫痫）。

## 骨折、车祸与脊柱损伤搬运
用硬板、托盘或厚书本作担架，毛毯包裹限制活动，尽量保持头颈与躯干一条直线，避免弯折脊柱；后肢或骨盆损伤可用软担架但需固定；搬运时人要在旁扶稳，疼痛动物可能咬人（可用毛巾包头、必要时临时嘴套，但呼吸困难者禁用嘴套）。不要喂食喂水（可能需急诊麻醉手术），不要用人类跌打药酒或自行复位。车祸后即使外观无恙也应就诊排查内脏出血、膀胱破裂与迟发性气胸。

## 中暑（热射病）
犬正常体温约 38.0～39.2 ℃；超过 40 ℃ 为高热，达到 41～41.5 ℃ 即为热射病，可引发多器官功能障碍、弥散性血管内凝血与肾衰，且这些可在 24～72 小时后才显现——**即使降温后看起来恢复了，也必须就诊检查**。

正确做法：立即离开热源，用**凉水或常温水**淋湿全身（尤其颈部、腋下、腹股沟），配合风扇或空调吹风，可在腋下与腹股沟放置冰袋隔布冷敷，用湿毛巾反复更换；用水淋湿后送医，途中持续通风。降温到约 39.4 ℃ 即应停止，以防过度降温。

禁止：冰水浸浴（使外周血管收缩反而阻碍散热）、酒精擦拭（可经皮与吸入中毒）、把狗裹在湿毛巾里（阻碍蒸发）、喂人类退烧药、强迫大量灌水、把湿毛吹干后再等。预防永远优先：绝不能把动物留在停放车辆内（30 ℃ 气温下十几分钟即可致命）、夏季避开 10:00～18:00 遛狗、短鼻犬猫与肥胖老年动物风险更高。

## 低血糖（幼犬、玩具犬、病弱猫）
表现：虚弱、发抖、站立不稳、眼神发直、抽搐、昏迷。高危个体是 6 月龄内玩具犬幼犬、小型犬、以及患肝胆疾病的猫。

处置边界：**仅当动物清醒且能自主吞咽时**，可用少量糖浆或蜂蜜涂抹在牙龈上（不是灌喂），随后立即进食并测血糖/送医；昏迷或抽搐者禁止喂任何液体（误吸致命），直接急诊静脉补糖。反复低血糖必须查因（胰岛素瘤、门脉短路、脓毒症、Addison 病等）。

## 胃扭转（GDV）
高危：大型/深胸犬（大丹、德牧、爱尔兰塞特、圣伯纳等），进食后剧烈活动、一次性大量饮水、老年犬风险更高。典型三联表现：**干呕但吐不出东西、腹围迅速膨大、流涎与休克征（牙龈苍白、心率快、虚弱）**。禁止催吐、禁止灌水、不要等待「排气」，直接送往有手术条件的医院并提前电话告知（GDV 需急诊手术，延误与死亡率高度相关）。

## 猫尿道阻塞：按小时计的急症
公猫尿道细长，完全阻塞会在约 36～48 小时内造成尿毒症，并因高血钾（钾离子超过约 7.5 mEq/dL 可致心脏骤停）在约 72 小时内死亡。识别要点：反复进出猫砂盆、蹲下用力却只有很小尿团或完全没有尿团、嚎叫、舔下腹部/生殖器、精神差、呕吐。

家庭禁做：不要挤压腹部或「帮它把尿挤出来」（可致膀胱破裂）、不要喂利尿剂或偏方、不要「等明天白天再看」。出现上述表现立即急诊，正规处理是镇静/麻醉下导尿、留置导尿管 1～3 天、静脉输液纠正电解质与监测心律。

## 误吞异物的观察边界
吞下异物后不要自行催吐、不要喂泻药或大量油、不要指望「吃韭菜裹出来」。以下情况直接急诊：线状/绳状异物（猫舔线、针线，可造成肠管切割与穿孔，属最高危情形）、尖锐物、纽扣电池、两枚以上磁铁或磁铁+金属、大型果骨/熟禽骨、已经出现呕吐腹痛拒食或粪便减少。

普通小物件（软橡胶块、短骨）在动物状态良好时可观察，但如果**36～48 小时内没有随粪便排出**，通常需要手术取出；观察期间每天检查粪便并把呕吐、食欲、精神状态变化记录下来给医生看。

## 蜂蜇、蛇咬与其他
- 蜂蜇：仅冷敷、限制活动、检查有无多处蜇伤。**出现面部或喉部肿胀、呼吸急促、呕吐、虚脱＝过敏性休克，立即急诊**。口服抗组胺药是否可用、用什么剂量必须由兽医决定，不要自行给药。
- 蛇咬：保持动物安静、让受伤肢体低于心脏、尽快送医。**不要切开伤口、不要尝试吸吮、不上止血带、不冰敷、不电击、不要去追打或捕捉蛇**（远距离拍照有助鉴定）。
- 眼部损伤：遮光、不按压、不用任何人用眼药水，立即就诊。
- 注射/用药后异常：任何疫苗或驱虫药后出现震颤、走路不稳、呼吸异常、注射部位迅速肿大，立即停药并回院，不要在家观察。

## 猫狗差异速览
| 情形 | 犬 | 猫 |
| --- | --- | --- |
| 呼吸窘迫 | 可见喘气、咳嗽 | **张口呼吸/腹式呼吸＝急症**；心衰常不咳嗽，只表现呼吸变快、躲藏 |
| 完全拒食 | 可耐受较久但仍需查因 | **24 小时就诊，48～72 小时有脂肪肝致命风险** |
| 尿闭 | 可见于结石 | **公猫最常见，24～48 小时可猝死** |
| 胃扭转 | 大型深胸犬急症 | 罕见 |
| 中暑 | 高发 | 少见但张口喘息即为警报 |
| 低血糖 | 幼犬与玩具犬 | 更多见于肝胆疾病，皮肤黄疸易被漏看 |
| 疼痛表达 | 跛行、嚎叫较明显 | **隐蔽**，可能只表现为不爱跳、速度慢、躲藏、性格变化 |
