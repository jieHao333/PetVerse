# 症状速查与就医紧迫度

本表按主人描述的「表现」组织，用来快速判断紧迫度与准备就诊信息。**它不是诊断**：同一症状可能对应从饮食不当到器官衰竭的多种原因，凡列在「立即」一栏的表现都必须当天就医。

## 按表现查
| 表现 | 常见可能原因 | 紧迫度 | 就诊前请准备 |
| --- | --- | --- | --- |
| 呕吐 1～2 次、精神食欲正常 | 吃太快、偷食、轻微饮食不当、毛球 | 可在家观察 12～24 小时，少量多次给水与清淡复食 | 呕吐物照片、时间、进食内容 |
| 持续呕吐或一喝水就吐 | 异物梗阻、胰腺炎、肠胃炎、中毒、肾病、尿闭 | **立即** | 禁食禁水直至就诊，记录次数与性状 |
| 呕血或咖啡渣样呕吐物 | 胃溃疡、非甾体抗炎药中毒、异物损伤、凝血障碍 | **立即** | 带上所有药品包装 |
| 弓背、不肯被摸肚子、祈祷姿势 | 腹痛（胰腺炎、肠炎、尿路疾病、子宫蓄脓） | **立即** | 记录疼痛持续时间 |
| 腹泻成形软便、无其他异常 | 换粮过快、零食过量、应激 | 观察 24～48 小时，恢复原粮、可加益生菌 | 粪便照片 |
| 水样腹泻频繁、带血或黏液 | 寄生虫（贾第虫、球虫）、细小/猫瘟、细菌性肠炎、中毒 | **立即**（幼宠未免疫按急症） | 粪检样本（1 小时内新鲜）、疫苗记录 |
| 黑柏油样便 | 上消化道出血 | **立即** | 照片＋用药清单 |
| 完全不吃 | 口腔疼痛、恶心、发热、应激、内科病；猫有脂肪肝风险 | 犬观察 24 小时；**猫超过 24 小时就诊** | 记录最后一次进食时间与量 |
| 多饮多尿 | 肾病、糖尿病、子宫蓄脓、甲亢（猫）、尿崩 | 尽快（1～3 天内） | 24 小时饮水量计量、尿团数量与大小 |
| 体重下降但食欲旺盛 | 甲亢（猫）、糖尿病、肠道吸收不良、肿瘤、寄生虫 | 尽快 | 每周体重记录 |
| 精神差、嗜睡、叫无反应 | 发热、疼痛、脱水、低血糖、休克、器官疾病 | **立即** | 体温、牙龈颜色与回血时间 |
| 牙龈苍白/发紫/发黄 | 贫血、缺氧、黄疸（肝胆或溶血） | **立即** | 拍照（自然光下），说明出现时间 |
| 皮肤黄染、尿色深如茶/酱油 | 肝胆疾病、溶血、中毒（洋葱/止痛药/百合） | **立即** | 接触史清单与时间 |
| 公猫蹲猫砂盆无尿团、嚎叫 | 尿道阻塞 | **立即，按小时计** | 不要按压腹部；记录最后一次排出尿团时间 |
| 尿频、尿血、尿液滴出 | 膀胱炎、结石、感染、（未绝育公犬）前列腺 | 尽快；伴无尿则**立即** | 中段尿样本或尿垫照片 |
| 咳嗽（犬，干咳如鹅鸣） | 犬窝咳、气管塌陷、心衰、异物刺激 | 多数尽快；伴呼吸急促则**立即** | 录一段咳嗽视频 |
| 猫咳嗽/母鸡蹲干呕、喘鸣 | 猫哮喘、气道疾病（常被误认吐毛球） | 尽快；张口呼吸则**立即** | 录像、发作场景描述 |
| 呼吸急促（安静时>30 次/分）、腹式呼吸、张口呼吸 | 肺水肿、胸水、哮喘、贫血、中暑、疼痛 | **立即** | 记录计数时的状态（睡眠/清醒） |
| 打喷嚏＋脓性眼鼻分泌物（猫） | 上呼吸道感染（疱疹/杯状/衣原体）、异物 | 尽快；幼猫或拒食则**立即** | 是否进食、有无接触其他猫 |
| 眼分泌物增多、眯眼、怕光 | 结膜炎、角膜溃疡、干眼症、青光眼 | 尽快；角膜发白/凸出则**立即** | 是否抓眼、单侧还是双侧 |
| 跛行、跳几步后恢复 | 髌骨脱位、轻度扭伤 | 尽快（1 周内） | 步态视频（正面/侧面/慢动作） |
| 突发不能站立、后肢瘫、大小便失禁 | 椎间盘突出、血栓（猫）、外伤 | **立即，硬板平移送医** | 记录发作时间、能否感觉到脚趾被捏 |
| 关节肿胀发热、不愿走动 | 感染、免疫介导、关节炎、骨折 | 尽快 | 发病诱因（外伤、有无明确撞击、还是无诱因出现） |
| 瘙痒剧烈、抓出血 | 寄生虫（跳蚤、疥螨）、过敏、皮肤感染 | 尽快；伴发热精神差则**立即** | 驱虫记录、饮食史、是否季节性 |
| 脱毛圆斑伴皮屑 | 皮肤癣菌（猫癣）、螨、局部摩擦 | 尽快（有家人尤其孕妇儿童出现皮疹时同步就医） | 是否接触流浪/其他宠物 |
| 下颌黑色煤渣样点（猫） | 猫痤疮（黑下巴） | 轻度可家庭护理 2～4 周；脓疱疼痛出血则就诊 | 食盆材质、清洁频率 |
| 口臭、流涎、牙石、吃饭掉食 | 牙周病、牙折、猫口炎、牙吸收 | 尽快 | 是否消瘦、单侧咀嚼 |
| 面部或眼下肿胀、单侧脓性鼻涕 | 牙根感染/口鼻瘘、脓肿、肿瘤 | 尽快；伴发热拒食则**立即** | 口腔照片 |
| 腹部膨大（未怀孕） | 子宫蓄脓、腹水、肿瘤、胃肠胀气、妊娠 | **尽快/立即**（伴精神差、呕吐、呼吸受限） | 发情时间、绝育状态 |
| 抽搐、意识丧失 | 癫痫、中毒、低血糖、脑病、电解质紊乱 | **立即** | 发作起止时间、发作前后行为、可能接触物 |
| 晕厥、突然倒地后自行恢复 | 心律失常、贫血、低血糖、癫痫 | **立即** | 发作场景（运动时/休息时）、恢复时长 |
| 皮肤或皮下肿块 | 脂肪瘤、囊肿、脓肿、肥大细胞瘤、其他肿瘤 | 尽快；快速增大或破溃则更急 | 每周同角度拍照并量直径、质地软硬、能否推动、是否疼痛 |
| 呕吐＋腹泻＋刚接触植物/药物/巧克力 | 中毒 | **立即，带包装或植物样本** | 摄入时间、估算量、体重 |
| 疫苗或驱虫药后 30 分钟～数小时异常 | 过敏反应、药物不良反应（含猫氯菊酯中毒） | **立即回院/急诊** | 药名与批号、给药时间 |

## 高危人群与更高门槛
幼宠（低血糖与脱水快、传染病风险）、老年动物（肾病心衰糖尿病隐匿）、孕期与产后母兽（子痫、难产、子宫蓄脓）、短鼻与深胸品种（中暑与 GDV）、玩具犬品种（低血糖）、肥胖个体（麻醉、关节、泌尿）、免疫抑制或化疗中的动物（感染表现被掩盖）。这些情形应把「观察一天」的默认值下调为当天就诊。

## 家庭急救箱建议内容
体温计（宠物专用或耳温）、纱布与自粘绷带、无刺激止血粉、生理盐水（冲洗伤口与眼）、氯己定稀释液（皮肤清洁）、一次性手套与伊丽莎白圈、尖头镊子（拔蜱）、3% 双氧水仅在兽医电话明确指导下用于犬（**猫禁用**）、常用药清单与疫苗本、宠物医院与急诊电话、毒物咨询联系方式。每 6 个月检查有效期并补充。
